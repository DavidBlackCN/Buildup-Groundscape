# Buildup Groundscape · 地表织景

Minecraft **26.3 / Fabric / Java 25** 的地表建筑装饰 Mod。提供五种材质、四种形态，共 **20 个独立方块**。1.2.1 修正 S1 的台阶厚度方向和覆盖集中问题，**默认关闭自然生成**；手动建筑功能不受影响。自然生成仅使用薄层，旧计划的楼梯/半砖地形替换不再执行。S2 新材质与第三方地形适配未实现。

| 材质 | 完整方块 | 1–8 层薄层 | 半砖 | 楼梯 |
|---|---|---|---|---|
| 草地 Grass | ✓ | ✓ | ✓ | ✓ |
| 菌丝 Mycelium | ✓ | ✓ | ✓ | ✓ |
| 灰化土 Podzol | ✓ | ✓ | ✓ | ✓ |
| 绯红菌岩 Crimson Nylium | ✓ | ✓ | ✓ | ✓ |
| 诡异菌岩 Warped Nylium | ✓ | ✓ | ✓ | ✓ |

## 安装

1. 使用 Minecraft **26.3**、Java **25** 和 Fabric Loader **0.20.1 或兼容的后续版本**。
2. 安装适用于 26.3 的 **Fabric API 0.165.0+26.3 或兼容的后续版本**。
3. 将 `build/libs/buildup-groundscape-1.2.1.jar` 放入客户端及专服的 `mods` 目录。不要安装 `-sources.jar`。

客户端和服务器都需要安装。本项目不包含 Forge/NeoForge 版本，也不声明支持其他 Minecraft 版本。发行前建议先在测试世界验收。

## 使用

- 在创造模式的“自然方块”分类查找，或搜索“草皮 / Sod”。提供简体中文、英文物品与标签名称。
- 薄层每层高 **1/8 格**，手持同材质薄层点击顶面叠加，Shift 同样可叠加；侧面点击在相邻有支撑位置放置。
- 八层保持薄层方块身份和防刷怪能力；再放一个会在其上方开始新的一层。拆除按层数掉落。
- 薄层需要下方完整顶面支撑；支撑消失时掉落。不允许直接放进水或岩浆，不支持含水。
- 半砖支持上下半、合并双层和含水；楼梯支持四向、倒置、内外转角和含水，行为沿用原版。
- 三种主世界材质用锹挖掘；两种菌岩用镐。硬度、音效、抗爆、工具要求及地图基础颜色取自对应原版方块。
- 所有形态是稳定装饰方块，不扩散、不退化为泥土/下界岩，不执行草地生长或骨粉繁殖。
- 1–7 层薄层允许下方原版草方块、菌丝和菌岩维持生长条件；8 层仍按完整遮光处理，下方原版地表可能退化。
- 薄层阻止普通地面自然生成的生物在其表面或所在格生成；不拦截命令、刷怪蛋或其他 Mod 强制生成。

例如：`/give @s buildup_groundscape:grass_sod_patch 64`。所有 ID 为 `buildup_groundscape:<材质>_sod_<形态>`；材质见上表英文对应的 snake_case，形态为 `block / patch / slab / stairs`。

## 生存配方与回收

这些是本项目的原创配方，并非对参考 Mod 配方的逐项复制。需要先取得相应原版地表方块，通常依赖精准采集。

| 输入 | 输出 | 摆放 |
|---|---|---|
| 1 对应原版草方块/菌丝/灰化土/菌岩 | 1 完整草皮方块 | 无序 |
| 1 完整草皮方块 | 8 草皮薄层 | 无序 |
| 8 同材质草皮薄层 | 1 完整草皮方块 | 无序，工作台 |
| 3 完整草皮方块 | 6 草皮半砖 | 横向一排 |
| 2 同材质草皮半砖 | 1 完整草皮方块 | 无序 |
| 6 完整草皮方块 | 8 草皮楼梯 | 原版楼梯形配方 |
| 1 草皮楼梯 | 6 草皮薄层 | 无序 |
| 1 草皮半砖 | 4 草皮薄层 | 无序 |

材料单位为完整方块 8、薄层 1、半砖 4、楼梯 6，各路线守恒。草皮不能反合成为原版方块。正常工具挖掘时，完整方块/楼梯掉落自身，双半砖掉落 2 个半砖，薄层掉落对应层数；精准采集和时运不增加数量。爆炸可能减少回收量。

## 外观和兼容性

草皮使用原创的“所有表面覆盖地表材质”模型：顶面、侧面、底面都引用对应原版顶面纹理。草地所有表面使用当前位置的原版群系草色，其余材质不套用草绿色。纹理未复制进 Mod，资源包对这些原版纹理的替换会作用于草皮。

R0–R4 已实测原版客户端及专服、五种纹理的诊断资源包替换、群系 tint、260 个干状态保存重开、原版地图 20 变体默认状态的真实像素采样。下列可选组合为 **1.0.0 的历史基线**，尚未重测 1.2.1 开启自然生成的组合；这些组件不是本 Mod 的必需依赖，也没有打包到发行 Jar。

| 实测可选组合 | 已通过 | 仍待验收 |
|---|---|---|
| Xaero's Minimap 26.6.1 | 加载、默认地表展示；截图可见展示区材质色条 | 全部材质精确色值、洞穴/其他模式、不同高度与缩放 |
| Iris 1.11.7 + Sodium 0.9.2 + Complementary Reimagined r5.9.3 + SPBR 22.5（RP_MODE=3） | 完整客户端测试、光影场景、法线/高光图集创建、资源重载、存档与专服交互 | 每种面、形态的法线/反射与原版精确对照；其他光影/PBR 包 |

不声明所有光影、小地图或配方查看器兼容。全表面设计、8 层上限、配方和掉落属于独立原创决定，未实测参考 Mod 的精确行为。

## 构建与验证

工具链固定为 Minecraft 26.3、Java 25、Gradle 9.8.2、Loom 1.19.3、Loader 0.20.1、Fabric API 0.165.0+26.3。使用官方去混淆名称，无 Yarn/Remap 插件或自定义 Mixin。

```powershell
# JAVA_HOME 应指向本机 JDK 25；示例路径请按安装位置调整。
$env:JAVA_HOME = 'C:/Program Files/Java/jdk-25.0.3'
.\gradlew.bat runDatagen
python scripts/verify_resources.py
.\gradlew.bat build
.\gradlew.bat runClientGameTest
```

`build` 包含真实专用 GameTest 服务器测试；客户端测试另外运行，需要可用图形环境。`test` 没有另设 JUnit 用例，不能将其 `NO-SOURCE` 当作测试通过。`runClient` / `runServer` 可启动普通开发环境。首次普通专服启动需要阅读并接受其生成的 `run/eula.txt`；测试环境通过 Loom 的 `configureTests` 单独配置。

`src/main/generated` 的 JSON 由 Fabric Datagen 生成并纳入产物，请修改生成器而非手改输出。Python 3 仅用于资源审计，不是玩家依赖。测试 Mod 位于 `src/gametest`，不会打包进发行 Jar。客户端测试自动创建展示世界及原创棋盘资源包，结果留在 `build/run/clientGameTest/`。

工作报告、归档日志和截图保存在项目仓库外的 `../docs/`，不纳入 Git。坡面 GameTest 的统计与自然生成对照测试写入 `../docs/evidence/s1-fix/`；Gradle 和 Minecraft 自身的临时输出仍位于已忽略的 `build/`、`run/`。自然生成对照按 `off`、`on`、`off_reverse`、`repeat` 顺序执行 `./gradlew runClientGameTest -PworldgenTest=<模式>`，之后可运行 `scripts/audit_s1_edges.py --minecraft-common-jar <Minecraft公共Jar路径>` 审计快照；`--evidence-dir` 可指定其他证据目录。克隆仓库不需要已有工作报告即可构建。

## S1 坡面感知自然薄层

首次启动生成 `config/buildup_groundscape-worldgen.json`：

```json
{
  "enabled": false,
  "density": 0.12,
  "maxLayers": 7,
  "slopeInfluence": 0.55,
  "flatCoverage": 0.10,
  "layerScale": 1.0,
  "heightVariation": 0.35
}
```

在测试世界使用：关闭游戏或服务器，将 `enabled` 改为 `true`，重启后探索**新生成区块**。单人游戏读取本机配置，专服读取服务器配置；客户端的配置不决定服务器地形。配置只在启动时读取，修改后需重启。

- 自然生成只添加 1–7 层薄层，不替换地表为楼梯或半砖，不扫描/回填旧区块。关闭开关不会删除已经生成的薄层。
- 原生 Feature 标记候选新区块，待相邻区块的原版装饰完成后，在该区块首次转为完整区块时添加薄层，避免打乱植物生成。没有逐刻扫描或额外区块加载。
- `density` 范围为 0–0.35，控制成片分布强度，并非承诺的最终覆盖率；0 不生成。`maxLayers` 必须为 1–7 的整数。旧配置显式填写的 3 不会自动升为 7，缺失的新字段采用默认值。
- 只识别五种原版地表与原版群系；跳过积雪/寒冷地面、植物、流体、缺乏支撑的边缘和已知结构涉及的区块。没有第三方材质映射或 Terralith/Tectonic 适配承诺。
- 薄层会减少可自然刷怪的地表，长期生态影响尚不能完整证明受控，因此保持实验开关且默认关闭。未知结构仍不能保证百分之百识别。
- 原版新区块的初始动物生成早于薄层提交；防刷怪规则作用于之后的自然刷新，不保证初次动物数量减少。
- 配置损坏或类型/范围错误时保留原文件、记录日志并禁用生成，不静默覆盖用户配置。

S1 使用固定 5×5 范围内的原始地表高度和相邻台阶位置决定坡向与厚度。1.2.1 增加四个紧邻方向的高度检查，薄层朝上方台阶增厚，外露下坡边沿不再额外垫高；同一小段坡面共享朝上方台阶投影的噪声采样位置。覆盖使用以 12 格尺度为主的连续噪声，减少旧版由 48 格尺度主导的大块密集/空白区域，并限制片区边缘的厚度变化。平地仍有少量低层覆盖。采样只读取现有区块缓存，不触发额外区块生成；危险位置仍跳过，不能保证所有山坡都有薄层。

| 参数 | 默认值 / 范围 | 调整效果 |
|---|---|---|
| `slopeInfluence` | 0.55 / 0–1 | 提高时坡面更容易被连续覆盖；不改变安全检查 |
| `flatCoverage` | 0.10 / 0–1 | 提高时平地覆盖增多；0 禁止完全平坦位置生成 |
| `layerScale` | 1.0 / 0.5–1.5 | 坡面厚度倍率；可提高到 1.2–1.4 观察更多高层 |
| `heightVariation` | 0.35 / 0–1 | 坡面厚度的连续噪声扰动幅度 |

默认参数需要在你的整合包和偏好下做最终实机验收。覆盖过密时，可先将 `density` 从 0.12 降到 0.10 或 0.08；多层偏少时，先确认 `maxLayers: 7`，再小幅提高 `layerScale`。每次修改后完整重启，在新世界或全新生成区块中对比；不会重算已经生成的薄层。S2 新材质尚未开始。
