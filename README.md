# Buildup Groundscape · 地表织景

Minecraft **26.3 / Fabric / Java 25** 的地表建筑装饰 Mod。提供十一种地表材质的 38 个建筑方块，以及十四种原版树叶薄层，共 **52 个独立方块**，支持 22 种植物/地面装饰共存与手动种植。提供 YACL 配置热应用；所有薄层采用覆地苔藓挖掘速度、仅精准采集掉落。1.6.1 起，薄层 **1–3 层可被水冲掉，4–8 层抗水冲刷，全部不含水**。**默认关闭自然生成**；自然生成仅使用薄层，不替换原始完整地表，不生成楼梯或台阶。第三方地形适配尚未实现。

## 安装

1. 使用 Minecraft **26.3**、Java **25** 和 Fabric Loader **0.20.1 或兼容的后续版本**。
2. 安装适用于 26.3 的 **Fabric API 0.165.0+26.3 或兼容的后续版本**。
3. 客户端及专服均安装必选前置 [YACL](https://modrinth.com/mod/yacl)，版本 **3.9.7+26.3-fabric**。本 Mod 不内嵌 YACL。
4. 将 `build/libs/buildup-groundscape-1.6.1.jar` 放入客户端及专服的 `mods` 目录。不要安装 `-sources.jar`，同一实例只保留一个版本。客户端可选安装 **Mod Menu 21.0.0**，提供模组列表配置入口。

客户端和服务器都需要安装。本项目不包含 Forge/NeoForge 版本，也不声明支持其他 Minecraft 版本。发行前建议先在测试世界验收。

## 配置页面与热应用

- 游戏内输入 `/groundscape-config` 打开 YACL 页面；安装 Mod Menu 时，也可从模组列表的配置按钮进入。YACL 是必选前置，Mod Menu 可选。
- 界面覆盖全部 38 个配置值：地表与坡面 7 项、六种材质各 2 项、树叶生成 5 项、十四个树种开关。支持中文、英文、范围限制、取消、撤销和恢复默认值。
- 编辑过程中不改变世界；点击保存，服务端确认并成功写入文件后才应用。恢复默认值也需要保存。单人主机可编辑，多人普通玩家只读，服务器管理员（原版权限等级 3 或以上）可保存。保存时重新校验权限与配置版本，拒绝过期页面覆盖较新的配置。
- 主菜单编辑本机配置，游戏内编辑当前服务器配置；同一实例的配置作用于其各存档，不是每个存档单独保存。远程服务器配置不会覆盖客户端本机文件。
- 继续使用 `config/buildup_groundscape-worldgen.json`，兼容旧字段。手动编辑文件后，服务器控制台或管理员执行 `/groundscape reload` 热重载；无效文件保留，当前生效设置不变。
- 总开关、树叶开关和所有生成参数都无需重启。但只影响尚未处理的新区块，不会在眼前补铺、删除或重算旧地形；修改前后的区域可能有密度差异。一次装饰操作使用固定配置快照。
- 总开关和树叶独立开关仍默认关闭；页面会明确显示树叶开关状态以及总开关的影响。

## 使用

- 在创造模式的“自然方块”分类查找，或搜索“草皮 / Sod”、新增材质名称。提供简体中文、英文物品与标签名称。
- 薄层每层高 **1/8 格**，手持同材质薄层点击顶面叠加，Shift 同样可叠加；侧面点击在相邻有支撑位置放置。
- 八层保持薄层方块身份和防刷怪能力；再放一个会在其上方开始新的一层。仅精准采集挖掘按层数掉落，普通工具、普通剪刀和时运不掉落薄层物品。
- 全部 25 种薄层需要下方完整顶面支撑，不支持含水。1–3 层在水实际流入或水桶向其位置放水时被冲掉；4–8 层阻止水进入所在格，水桶可按原版规则改在相邻格放水。4–7 层上半格的空隙也不会填水。不会仅因旁边有水就消失，不允许直接放进水或岩浆。爆炸、冲刷及失去支撑不掉落薄层；共存植物仍独立使用原版掉落规则，厚薄层所在格挡住水时保留共存植物。植物上方空间检查保持原有行为。
- 半砖支持上下半、合并双层和含水；楼梯支持四向、倒置、内外转角和含水，行为沿用原版。
- 所有薄层硬度均为覆地苔藓的 **0.1**，锄头加速，1–8 层不增加挖掘时间。其他形态仍继承对应材质的挖掘规则：主世界材质用锹、菌岩用镐。材质音效、抗爆与地图基础颜色保留。
- 沙子、红沙和沙砾的新增变种不受重力影响；薄层失去支撑会消失且不掉落物品。原版完整沙子、红沙和沙砾保持原行为。
- 地表建筑材质不扩散、不退化为泥土/下界岩，也不会自行长出植物。已共存植物的部分骨粉操作见下文。
- 自然生成可保留已支持的原版植物和地面装饰，显示在薄层实际顶面。创造和生存模式均先用左键打掉植物，再挖掘薄层；第一次保留原有材质和层数，植物采用原版挖掘速度、掉落及工具耐久规则。生存模式剪刀按对应植物的原版规则采集，创造模式不掉落。右键不除草；植物不增加实体碰撞。上方方块侵入植物所需空间时，植物脱落，薄层保留。
- 1–7 层薄层允许下方原版草方块、菌丝和菌岩维持生长条件；8 层仍按完整遮光处理，下方原版地表可能退化。
- 薄层阻止普通地面自然生成的生物在其表面或所在格生成；不拦截命令、刷怪蛋或其他 Mod 强制生成。

例如：`/give @s buildup_groundscape:grass_sod_patch 64`。原有五种材质 ID 保持 `buildup_groundscape:<材质>_sod_<形态>`，形态为 `block / patch / slab / stairs`。六种新增材质使用 `<材质>_<形态>`，仅提供 `patch / slab / stairs`，例如 `sand_patch`、`coarse_dirt_slab`、`rooted_dirt_stairs`。

## 植物共存与手动种植

支持矮草、蕨、蒲公英、虞美人、兰花、绒球葱、蓝花美耳草、红/橙/白/粉红郁金香、滨菊、矢车菊、铃兰、成熟火把花、枯萎的灌木、矮干草、高干草、小型灌木（`minecraft:bush`），以及枯叶堆、野花簇和粉红色花簇。后三者保留原版的 1–4 数量及四向朝向，共计 67 个非空植物状态。

- 手持原版植物物品右键薄层顶面，按该薄层对应的原版完整基底判断是否合法；例如沙子上的干旱植物按沙子的规则判断。成功后生存模式消耗一份物品，创造模式不消耗。空间不足或不支持的组合不消耗物品。
- 1–7 层在同格保存植物；裸八层薄层上手动种植使用上方的独立原版方块。旧存档八层共存状态仍可加载。
- 同种枯叶堆或花簇可右键追加到四份，不能覆盖另一种植物。首次左键按该植物状态的原版掉落结算，不掉薄层。
- 花簇可使用骨粉增加数量，满四份后产出对应物品；矮干草可长成高干草，高干草和小型灌木使用原版邻近扩散规则。共存矮草/蕨变成两格高植物暂不支持，不会无效消耗骨粉。
- 手动放置薄层时，若目标格已有支持的植物，会保留植物状态；手持同材质薄层仍可叠高，并检查植物空间。
- 两格高植物、树苗、作物、水生植物、特殊行为花卉及第三方植物尚未纳入共存。复合方块不等同于所有生态系统中的独立植物，例如未实现复合花卉的蜜蜂授粉适配。

## 树叶薄层

提供橡树、云杉、白桦、丛林、金合欢、深色橡树、红树、樱花、苍白橡树、杜鹃、盛开的杜鹃，以及红/橙/黄色杨树，共十四种薄层，ID 为 `buildup_groundscape:<树种>_leaves_patch`，例如 `oak_leaves_patch`、`red_poplar_leaves_patch`。树叶不提供台阶或楼梯。

手动支持 1–8 层，使用对应原版树叶纹理和颜色；不腐烂、不参与树干距离计算，失去支撑后消失且不掉落。树叶薄层同样 1–3 层可被水冲掉、4–8 层抗水冲刷，全部不含水；自然生成的 1–2 层仍可被水清理。每个原版树叶可合成八个薄层，八个薄层可合回一个原版树叶；仅精准采集拆除按层数掉落薄层，不额外产出树苗、苹果或木棍。树叶薄层不提供植物共存，也不与地表薄层同格混合。

自然生成需同时开启总开关和 `leafPatches.enabled`。在现有配置中添加以下字段即可，保留原有其他字段：

```json
"leafPatches": {
  "enabled": true,
  "coverage": 0.03,
  "maxLayers": 2,
  "searchHeight": 24,
  "maxPerChunk": 8,
  "types": { "oak": true, "birch": true, "cherry": true }
}
```

- 缺少整个 `leafPatches` 分组时默认关闭；分组内未列出的树种默认允许。开关只影响新区块生成，不删除方块或配方。总开关 `enabled: false` 禁止所有自然生成；草皮 `density: 0` 不会关闭已单独启用的树叶生成。
- `coverage` 范围 0–0.04，默认 0.03，控制原始候选小片比例；实际覆盖会因树冠、地表和安全检查而更低。小片通常 2–4 格，方向由世界种子确定，默认约九成候选是一层、一成两层。
- `maxLayers` 为 1–2，`searchHeight` 为 1–32，`maxPerChunk` 为 0–32；默认分别为 2、24、8。零覆盖或零数量上限会停止树叶生成。
- 只在主世界的安全地面、对应自然树冠下方放置。最近的上方树叶决定材质；遇到建筑、树干、持久树叶或禁用树种时不穿透继续搜索。超出搜索高度的树冠不会参与。
- 原有花草、枯叶堆、花簇和坡面薄层优先，树叶薄层不覆盖它们。不在已有薄层上叠放，不回填旧区块，不随玩家种树持续增加。沿用结构、流体、积雪和危险边缘保护。
- 使用世界坐标采样，跨格边界的小片不截断；超过区块上限时按种子排序选择，避免总从扫描起点开始填充。不增加区块加载，读写范围有界。

## 生存配方与回收

这些是本项目的原创配方，并非对参考 Mod 配方的逐项复制。需要先取得相应原版地表方块；原有五种草皮材质通常依赖精准采集。

| 输入 | 输出 | 摆放 |
|---|---|---|
| 1 对应原版草方块/菌丝/灰化土/菌岩 | 1 完整草皮方块 | 无序 |
| 1 完整草皮方块 | 8 草皮薄层 | 无序 |
| 8 同材质草皮薄层 | 1 完整草皮方块 | 无序，工作台 |
| 3 完整草皮方块 | 6 草皮半砖 | 横向一排 |
| 2 同材质草皮半砖 | 1 完整草皮方块 | 无序 |
| 6 完整草皮方块 | 8 草皮楼梯 | 原版楼梯形配方 |
| 1 草皮楼梯 | 6 草皮薄层 | 无序 |
| 1 草皮半砖 | 4 草皮薄层 | 无序 |

材料单位为完整方块 8、薄层 1、半砖 4、楼梯 6，各合成路线守恒。草皮不能反合成为原版方块。正常工具挖掘时，完整方块/楼梯掉落自身，双半砖掉落 2 个半砖；薄层仅精准采集掉落对应层数，时运不增加数量。薄层爆炸不掉落，其他形态爆炸可能减少回收量。

六种新增材质直接使用原版完整方块作为上表中的“完整草皮方块”，省略第一步转换。8 个薄层或 2 个台阶可回收为同材质的原版方块；其他比例保持不变。沙砾变种掉落自身，不额外随机掉落燧石。新泥土类变种不蔓延草、不耕作、不执行骨粉繁殖。

## 外观和兼容性

草皮使用原创的“所有表面覆盖地表材质”模型：顶面、侧面、底面都引用对应原版顶面纹理。草地所有表面使用当前位置的原版群系草色，其余材质不套用草绿色。纹理未复制进 Mod，资源包对这些原版纹理的替换会作用于草皮。

1.6.1 已通过 80 项服务端 GameTest，以及 6,678 个展示状态的客户端同步与保存重开、十四种树叶的原版着色和诊断资源包替换、创造/生存模式的专服种植及拆除交互回归。测试覆盖全部 25 种薄层 × 1–8 层的同工具覆地苔藓挖掘速度、精准采集掉落，以及横向/向下流水、水桶在 3/4 层边界的处理；另验证层数改变后抗水性立即变化。配置测试覆盖 38 项界面值、保存/取消/恢复默认、管理员权限与编辑冲突、命令重载和真实普通世界的热开启/关闭。YACL 3.9.7+26.3-fabric 本轮回归通过；可选 Mod Menu 21.0.0 入口保留 1.6.0 的验证记录。

## 构建与验证

工具链固定为 Minecraft 26.3、Java 25、Gradle 9.8.2、Loom 1.19.3、Loader 0.20.1、Fabric API 0.165.0+26.3，YACL 固定 3.9.7+26.3-fabric，Mod Menu 编译接口为 21.0.0。使用官方去混淆名称，无 Yarn/Remap 插件或本项目 Access Widener。两个客户端/服务端游戏模式 Mixin 负责植物优先拆除及客户端预测，在原版权限检查和 Fabric 拆除取消事件之后执行，裸薄层走原版拆除路径。植物基底 Invoker 与八层支撑注入复用原版种植条件。流体 Mixin 在墙面检查中忽略薄层碰撞，再通过流体准入判断拒绝水进入 4–8 层薄层；实体碰撞高度不变。成功准入后的流体替换与掉落沿用原版流程。

```powershell
# JAVA_HOME 应指向本机 JDK 25；示例路径请按安装位置调整。
$env:JAVA_HOME = 'C:/Program Files/Java/jdk-25.0.3'
.\gradlew.bat runDatagen
python scripts/verify_resources.py
.\gradlew.bat build
.\gradlew.bat runClientGameTest
.\gradlew.bat runClientGameTest -PconfigTest
```

`build` 包含真实专用 GameTest 服务器测试；客户端测试另外运行，需要可用图形环境。`test` 没有另设 JUnit 用例，不能将其 `NO-SOURCE` 当作测试通过。`runClient` / `runServer` 可启动普通开发环境。首次普通专服启动需要阅读并接受其生成的 `run/eula.txt`；测试环境通过 Loom 的 `configureTests` 单独配置。

`src/main/generated` 的 JSON 由 Fabric Datagen 生成并纳入产物，请修改生成器而非手改输出。Python 3 仅用于资源审计，不是玩家依赖。测试 Mod 位于 `src/gametest`，不会打包进发行 Jar。客户端测试自动创建展示世界及原创棋盘资源包，结果留在 `build/run/clientGameTest/`。

工作报告、归档日志和截图保存在项目仓库外的 `../docs/`，不纳入 Git。1.6.0 常规客户端与配置测试证据写入 `../docs/evidence/config-patch-rules/`；旧自然生成测试仍使用各自的仓库外证据目录。Gradle 和 Minecraft 自身的临时输出仍位于已忽略的 `build/`、`run/`。自然生成对照按 `off`、`on`、`off_reverse`、`repeat` 顺序执行 `./gradlew runClientGameTest -PworldgenTest=<模式>`，之后可运行 `scripts/audit_s1_edges.py --minecraft-common-jar <Minecraft公共Jar路径>` 审计快照；`--evidence-dir` 可指定其他证据目录。克隆仓库不需要已有工作报告即可构建。Datagen 与 build 请按上述命令分两次调用，避免同次任务图提前复制旧资源。

## S1 坡面感知自然薄层

首次启动生成 `config/buildup_groundscape-worldgen.json`：

```json
{
  "enabled": false,
  "density": 0.12,
  "maxLayers": 7,
  "slopeInfluence": 0.55,
  "flatCoverage": 0.10,
  "layerScale": 1.0,
  "heightVariation": 0.35,
  "materials": {
    "sand": { "enabled": true, "thicknessScale": 1.0 },
    "dirt": { "enabled": true, "thicknessScale": 1.0 },
    "coarse_dirt": { "enabled": true, "thicknessScale": 1.0 },
    "red_sand": { "enabled": true, "thicknessScale": 1.0 },
    "gravel": { "enabled": true, "thicknessScale": 1.0 },
    "rooted_dirt": { "enabled": true, "thicknessScale": 1.0 }
  }
}
```

在测试世界中打开配置页面，将 `enabled` 改为 `true` 并保存，无需重启即可探索**新生成区块**。单人游戏读取本机配置，专服读取服务器配置；客户端本机的配置不决定远程服务器地形。

- 自然生成只添加 1–7 层薄层，不替换地表为楼梯或半砖，不扫描/回填旧区块。关闭开关不会删除已经生成的薄层。
- 原生 Feature 标记候选新区块，待相邻区块的原版装饰完成后，在该区块首次转为完整区块时添加薄层，避免打乱植物生成。没有逐刻扫描或额外区块加载。
- `density` 范围为 0–0.35，0 不生成地表薄层，但不影响独立开启的树叶薄层。正值影响坡面厚度和平地覆盖倾向，不再用随机阈值整片排除安全坡面。`maxLayers` 必须为 1–7 的整数；厚度分布按上限缩放，避免将所有高层截成同一高度。旧配置显式填写的 3 不会自动升为 7，缺失的新字段采用默认值。
- 只识别上表十一种原版地表与原版群系；跳过积雪/寒冷地面、不支持共存的植物、流体和缺乏支撑的边缘。海滩仅放行通过安全检查的沙子、沙砾地基，海洋、河流、洞穴群系仍排除。结构部件周围保留水平 2 格、垂直 3 格缓冲；深地下结构不再直接排除整个地表区块。元数据不完整或超出固定处理上限时保守跳过。没有第三方材质映射或 Terralith/Tectonic 适配承诺。
- 六种新增材质通过 `materials` 独立控制。`enabled` 只控制该材质的自然生成，不删除方块或配方；`thicknessScale` 范围 0.5–1.5，默认 1，与全局厚度参数共同作用并遵守 `maxLayers`。原有配置缺省时使用这些默认值，读取时文件不会被自动改写，界面保存时会写出完整字段；全局关闭时所有材质都不生成。
- 共存是否合法由具体植物与原版基底条件决定；不再将沙子等材质统一视为“不能容纳植物”。原始地基决定薄层材质，混合材质共同参与坡向判断。缠根泥土仅在满足地表和安全要求的位置参与，不额外扫描地下。
- 薄层会减少可自然刷怪的地表，长期生态影响尚不能完整证明受控，因此保持实验开关且默认关闭。未知结构仍不能保证百分之百识别。
- 原版新区块的初始动物生成早于薄层提交；防刷怪规则作用于之后的自然刷新，不保证初次动物数量减少。
- 启动时配置损坏或类型/范围错误则保留原文件、记录日志并禁用生成；运行时保存或重载失败则保留当前生效配置，不静默覆盖原文件。

S1 使用固定 5×5 范围内的原始地表高度和相邻台阶位置决定坡向与厚度。1.3.0 中，通过安全检查且存在可衔接上方台阶的坡面连续参与生成，噪声调整厚度，不再决定整片坡面的有无。同一小段坡面共享朝上方台阶投影的噪声采样位置，越接近上方台阶越厚；外露下坡边沿仍不垫高。默认厚度可达到 7 层，平地仍只保留少量 1–2 层装饰。不会给每个平地格铺底，也不会削减原始完整地形；狭窄台阶、危险地形和保护区仍可能没有薄层。结构边界在原版 Feature 阶段从已有区块元数据采集，首次 FULL 阶段只在本区块写入；不额外请求区块生成。

| 参数 | 默认值 / 范围 | 调整效果 |
|---|---|---|
| `slopeInfluence` | 0.55 / 0–1 | 提高时坡面厚度增加；不改变安全检查和坡面的连续参与 |
| `flatCoverage` | 0.10 / 0–1 | 提高时平地覆盖增多；0 禁止完全平坦位置生成 |
| `layerScale` | 1.0 / 0.5–1.5 | 坡面厚度倍率；可提高到 1.2–1.4 观察更多高层 |
| `heightVariation` | 0.35 / 0–1 | 坡面厚度的连续噪声扰动幅度 |

默认参数需要在你的整合包和偏好下做最终实机验收。坡面显得太厚时，可将 `density` 从 0.12 降到 0.10 或 0.08，或降低 `layerScale`；这会降低厚度而非重新制造大片坡面空洞。平地过密则降低 `flatCoverage`。多层偏少时，先确认 `maxLayers: 7`，再小幅提高 `layerScale`。每次修改后完整重启，在新世界或全新生成区块中对比；不会重算已经生成的薄层。旧薄层状态仍可加载，升级不会自动给它们添加植物；新增方块和植物状态不承诺降级兼容。泥巴、黏土和灵魂系列不在本次范围内。
